# 更迭（ITERATION）｜科技史桌游

《更迭》是一款以科技发展史为主题的实体策略桌游测试版。玩家带领各自的文明跨越五个科技时代，通过收集资源、购买科技、触发专利、使用事件牌和建设奇观，争取率先达成胜利条件。本仓库收录实体版的打印资料和网页版试玩源码。

## 游戏目标与玩法

达到对应人数的科研点门槛即可获胜：2 人为 220 点，3 人为 160 点，4 人为 125 点。进入时代 V 后，玩家也可以花费科研点挑战最终科技；挑战成功同样立即获胜。

每回合依次处理持续效果、使用明置事件、抽取资源、掷骰并结算专利、购买科技、建设奇观、购买与明置事件，最后整理手牌。完整的准备流程、支付方式、时代更替和特殊情况见[说明书](docs/rules/rulebook.md)。卡面效果与通用规则冲突时，以卡面文字为准。
